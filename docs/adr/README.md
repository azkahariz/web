# Architecture Decision Records

ADR menyimpan **mengapa** keputusan arsitektur dan business semantics penting dibuat. Dokumen chapter menjelaskan cara kerja; diagram memberi navigasi visual; ADR menjaga rationale jangka panjang.

Buat ADR untuk perubahan source of truth, core semantics, auth/security boundary, identity/reference model, deployment topology, atau persistence model besar. Jangan buat ADR untuk CSS, refactor komponen kecil, atau bug fix sempit.
